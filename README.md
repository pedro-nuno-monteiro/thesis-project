# Wi‑Fi Sensing — Thesis Project

This repository contains code, notebooks and data used for a Wi‑Fi sensing experiment (thesis project).

## Notebooks

### `Data analysis.ipynb`
The current active notebook. Performs scenario analysis and comparison, including CSI magnitude processing, per-packet normalization, 3D visualisation, dataset construction (raw and PCA features), Random Forest training/evaluation, and a window/overlap parameter study.

## Contents
- `new_data/` — recent CSV files collected from the CSI devices. File naming convention: `SCENARIO_USER_ACTIVITY_ESP_TRIAL_DATETIME.csv`.
- `utils/` — helper scripts used by the notebooks (CSV importer, file renaming, etc.).
- `images/` — visualisation outputs generated by the notebooks (confusion matrices, heatmaps, position plots).
- `udp_server.py` — UDP server for receiving real-time CSI data from ESP devices and saving it to CSV files.
- `old/` — legacy notebooks, scripts and data from earlier experiments:
  - `General-Data-Collecting-[meu].ipynb` — earlier ML pipeline for user identification.
  - `Wi-Fi-Sensing-[meu].ipynb` — refactored version of Miguel's original project.
  - `Position-Selection-[meu].ipynb` — enhanced version of Diana's position detection notebook.
  - `Generalistic_WIFI_Sensing.ipynb` — early experimental notebook (not continued).
  - `csv_import.py` — legacy CSV organisation utility for the old naming convention.
  - `data/` — archived CSI datasets from prior experiments (multiple processing stages).
  - `deles/` — backup notebooks and scripts from collaborators.

## Requirements

Recommended: create and use a virtual environment before installing requirements.

```powershell
# from repository root (Windows PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate
pip install -r requirements.txt
```

## Usage
- Open and run the notebooks in a Jupyter environment (e.g. JupyterLab or VS Code).
- Primary notebook: `Data analysis.ipynb` — runs the full pipeline: read CSVs → process CSI → extract features → train/evaluate models.
- Helper scripts in `utils/` can be imported from notebooks (they are used in the notebooks already).
- Use `udp_server.py` to collect new CSI data from ESP devices over UDP; it saves files to `new_data/` using the standard naming convention.

## Data layout
- New CSI datasets are stored under `new_data/`. The notebooks expect files following the `SCENARIO_USER_ACTIVITY_ESP_TRIAL_DATETIME.csv` naming convention.
- Legacy datasets are kept under `old/data/` and are not used by the current notebook.

## Notes
- This repository is part of an academic thesis. Some notebooks and scripts are exploratory and contain inline comments in Portuguese.
- If you plan to reproduce results, check and adapt the absolute paths used in notebooks (they reference local OneDrive paths). Prefer using relative paths or set the `path` variable at the top of each notebook.
